# 🛡️ Industrial Quality Control & Inspection System

Тази система представлява високотехнологичен прототип за автоматизиран визуален контрол и детекция на аномалии в производствени компоненти, клетки или индустриални детайли.

## 🔬 Архитектура и Технологичен стек

- **ИИ Ядро:** OpenAI CLIP (ViT-B-32) – Zero-Shot Metric Learning архитектура.
- **Методология:** Косинусово сходство (Cosine Similarity) с Temperature Softmax Scaling за висока разделителна способност.
- **Интерфейс:** Streamlit Enterprise Dark Dashboard с Glassmorphism елементи.
- **Хардуерна автономност:** Локално капсуловано ядро, работещо изцяло на CPU/GPU без нужда от постоянна интернет връзка (Air-Gapped Ready).

## 🚀 Инструкции за локално стартиране

1. **Инициализиране на изолирана среда:**

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Инсталиране на производствените зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Стартиране на автономния контрол:**
   ```bash
   streamlit run app1.py
   ```

## ⚙️ Функция за качествен контрол (QC)

Системата има вграден динамичен **Праг за толеранс (Confidence Threshold)** в страничното меню. Ако ИИ измери сигурност под критичния праг, софтуерът автоматично блокира детайла и сигнализира за **Критична аномалия**, предпазвайки линията от дефектни компоненти.
